# Contributing

Contributions are welcome. Feel free to raise a pull request or open an issue , whether it's code, documentation, or just a suggestion.

- **Issues**: bug reports, ideas, and questions. For security-sensitive findings, please follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
- **Pull requests**: fork the repository, make your changes on a branch, open a PR with a short description of what and why.

If you're unsure how any of this works, the official GitHub guides are a great place to start:

- [Creating an issue](https://docs.github.com/en/issues/tracking-your-work-with-issues/creating-an-issue)
- [Fork a repository](https://docs.github.com/en/get-started/quickstart/fork-a-repo)
- [Creating a pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request)

By contributing, you agree that your contributions are licensed under the project's [license](LICENSE).

Thank you.
